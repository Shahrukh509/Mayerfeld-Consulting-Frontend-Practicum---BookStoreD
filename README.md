# Mayerfeld Bookstore

A responsive bookstore storefront built with **React** and **Tailwind CSS**, using Vite for development and production builds.

## Getting started

Install dependencies:

```sh
npm install
```

Start the development server:

```sh
npm run dev
```

## Available scripts

- `npm run dev` starts the Vite development server.
- `npm run build` creates a production build.
- `npm run preview` serves the production build locally.
- `npm run lint` runs ESLint.

## Storefront features

- Responsive bookstore navigation and hero section
- Book catalog with category filtering and quantity controls
- Staff recommendations, store highlights, and upcoming events
- Newsletter signup and cart quantity display
